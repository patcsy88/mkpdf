# ADR-0001: Record architecture decisions

Status: Proposed

## Context
The project has many decisions that are hard to reverse (ABI, dependencies, security). Agents and people join over time and need the reasons.

## Decision
Significant decisions are written as numbered ADRs in `docs/adr/` before they are merged.

## Alternatives
Decisions in issues or chat. Rejected: they are not versioned with the code.

## Consequences
A small cost per decision. Reviewers can check changes against the ADRs.
